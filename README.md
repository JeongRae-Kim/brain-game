# 가족 두뇌게임 (brain-game)

가족·지인이 카카오톡 링크로 들어와 **같은 시각에 같은 문제**를 각자 풀고 순위를 겨루는 웹 게임입니다.

- 게임: ⚡ 빨리 찾기(15문제, 틀리면 +2초) · 🃏 짝맞추기 · 🔢 스도쿠(초·중·고급, 힌트 +30초 최대 3개, 메모)
- 영어: 🔤 크로스워드 · 🔠 알파벳 맞추기(10문제) · 🟩 워들(3단어, 6번 안에, 실패 시 +60초) — 1~9등급(중1~고급), 힌트 +30초 최대 3개
- ⏰ 제한 시간: 영어 크로스워드 5/8/12분(1~3/4~6/7~9등급), 사자성어 4/6/10분, 워들 전체 10분·단어당 3분 — 다 못 풀면 점수로 환산(다 푼 사람 시간순 → 못 푼 사람 점수순)
- 📜 사자성어 크로스워드(초·중·고급, 보기 글자판 입력, 다 풀면 뜻 정리)
- 이미 나온 단어는 다음 판에서 빼고 냄(남은 단어가 적어지면 다시 처음부터)
- ⚙️ 단어 관리: 관리 코드(Firebase `adminCode`)로 들어가 영어·사자성어 목록 교체
- 💬 방 대화: 휴대폰은 오른쪽 아래 버튼, 넓은 화면은 오른쪽에 고정 · 빠른 답장 · 입장·완료·시작 자동 안내 · 최근 50개 보관
- 🏆 명예의 전당: 게임·난이도별 역대·이번 달 1~3위(1인 1기록, 다 푼 기록만)
- 📈 기록 변화: 사람·게임·난이도별 기록 그래프와 목록
- 방장 넘기기(다른 사람 이름 두 번 누르기), 🏳️ 포기 버튼
- 빨리 찾기·짝맞추기는 1~5단계: 직전 판 중간 기록이 빠르면 자동으로 한 단계 올라가고, 느리면 내려갑니다(방장이 ＋/－로 직접 조정 가능)
- 고정 방 주소: `https://jeongrae-kim.github.io/brain-game/?room=family`
- 로그인 없음 (Firebase 익명 인증), 이름만 입력

## 진행 방법
1. 단톡방 공지에 고정 방 링크를 올려 둡니다.
2. 처음 들어온 사람이 방장(👑)이 됩니다. 방장이 나가면 다음 사람이 이어받습니다.
3. 방장이 게임을 고르고 **시작**을 누르면 5초 뒤 모두에게 같은 문제가 열립니다.
4. 늦게 온 사람도 시작 후 10분 안에는 참여할 수 있습니다(본인 시작 시점부터 시간 측정).

다른 모임용 방은 `?room=friends`처럼 이름만 바꾸면 됩니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 (큰 글씨·큰 버튼) |
| `app.js` | 방 참여, 방장, 동시 시작, 순위 |
| `games.js` | 문제 생성·자동 단계 조절 (seed가 같으면 같은 문제) |
| `sudoku.js` | 스도쿠 생성기 (답이 하나뿐인 문제) |
| `words.js` | 영어 단어 목록 (1~9등급, `단어:뜻`) |
| `english.js` | 크로스워드·알파벳 맞추기·워들 문제 생성 |
| `ui-english.js` | 영어·사자성어 게임 화면 |
| `idioms.js` | 사자성어 목록·크로스워드 생성 |
| `config.js` | Firebase 웹 설정값 |
| `database.rules.json` | Realtime Database 보안 규칙 |

## Firebase 설정
1. Realtime Database 생성 (asia-southeast1)
2. Authentication → 익명 로그인 사용
3. Realtime Database → 규칙 탭에 `database.rules.json` 내용을 붙여넣고 게시
4. 웹 앱 설정값을 `config.js`에 입력
